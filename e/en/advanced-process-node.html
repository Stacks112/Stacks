Glossary

advanced process node

Measured in nanometers, a smaller number means more transistors fit in the same area, boosting performance and power efficiency. Reaching a finer node requires more precise, more expensive lithography tools, so the equipment a chipmaker can access effectively sets the ceiling on what chips it can build.
