CUDA CRACKS
Jukan (@jukan05) · 2026-07-23 · original: EN

Nvidia's real moat is software, not silicon. Can AI coding tools crack it in a year?

Open in the Stacks app → Read the original ↗

Semiconductor analyst Jukan says he has turned very bearish on Nvidia, and the trigger is a reportedly leaked investor call from DeepSeek founder Liang Wenfeng. The point is simple. What has really protected Nvidia is not chip speed but software, and AI coding tools are tearing that wall down fast. One thing to nail down first. Wenfeng's remarks come from a private call that was reportedly leaked. Neither he nor DeepSeek has confirmed them.

The wall isn't the chip?

CUDA is the software layer that lets developers run AI programs on Nvidia chips. It launched in 2006 and has built up for nearly two decades. Nvidia counts six million developers on it and more than 150 libraries. The catch is that years of written code are tied to those libraries. Moving to a rival's chip means rewriting all of it, and that switching cost is the moat. A slightly faster chip means nothing if the software can't come with it.

How did DeepSeek get around it?

When DeepSeek trained its V3 model, it already skipped CUDA for some tasks and wrote PTX directly. PTX sits one level below CUDA, closer to the chip. It takes more work but leans less on Nvidia's software. Then came TileLang, an open-source tool built by a Peking University group with Microsoft Research support. It re-emits the same code for different chips. If those tools are quickly fitted to Huawei chips with AI coding assistants, Wenfeng argues, the software gap for Chinese chips largely disappears within a year.

Huawei is already shipping chips for that software to run on: the Ascend 950 line and the Atlas 950 SuperPoD that bundles them. But every "several times Nvidia" figure Huawei points to is its own claim. No independent benchmark has verified it yet.

So how big is the gap?

Here the readings split head-on.

CFR's reading

The hardware gap is about 5x today and widens to 17x by 2027 (Dec 2025 report).

VS
Wenfeng's reading (leaked, unverified)

Just 4x per chip and two years, and once the software moves, even that is the only bottleneck left.

One side sees the same gap widening, the other sees it as narrow. Jukan's bearish case leans on the second, and the fact that the second rests on an unverified leak does not go away.

Is AMD the same story?

Jukan extends the logic into a bull case for AMD. AMD has ROCm, its own answer to CUDA. It is open source, started in 2016, and even in last week's release AMD writes that it is still closing the gap. The same AI coding tools could speed that work up, and AMD happens to be investing in Anthropic and using Claude Code for its own chip design. If the software wall really is getting lower, the benefit goes not only to Huawei but to AMD.

In three lines
  • Analyst Jukan has turned very bearish on Nvidia, citing a reportedly leaked call from DeepSeek's Liang Wenfeng.
  • His point: Nvidia's moat is software (CUDA), not silicon. DeepSeek already routed around it with its own tools and open-source TileLang.
  • Even if the software moves to Huawei chips, a hardware gap remains. Readings of that gap split between 4x (Wenfeng) and 17x (CFR).

Why it matters · If software tools, not scarce hardware, were the main thing keeping Chinese chipmakers and AMD locked out of Nvidia's ecosystem, then AI coding assistants closing that software gap would remove one of Nvidia's biggest competitive advantages years faster than expected, reshaping who captures the profits of the AI buildout.

Worth asking · If AI coding tools really can port DeepSeek's Huawei-ready software stack across in about a year, is Nvidia's CUDA moat cracking on a timeline the market hasn't priced in yet?

What happened next

Awaiting gradingGrade around mid-2027 whether Huawei's chip software ecosystem (DeepSeek's compiler and TileLang tooling) has closed the gap with CUDA as Wenfeng predicted, and whether Nvidia's China-exposed growth underperformed as a result.
